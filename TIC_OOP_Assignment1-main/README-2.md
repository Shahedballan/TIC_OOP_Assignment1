# Hardware Maintenance System

**Course:** IPG203 – Object-Oriented Programming (OOP)  
**Assignment:** TIC_OOP_Assignment1  
**Language:** C#

## Project Overview

This repository contains a team assignment for an object-oriented **Hardware Maintenance System**, intended to support the organization and management of appliance maintenance and repair operations.

The project is developed as a collaborative exercise in applying object-oriented programming concepts and documenting the resulting software.

## Objectives

- Organize a maintenance and repair workflow in a structured software project.
- Apply object-oriented programming principles using C#.
- Maintain project documentation, test cases, and a UML diagram.
- Collaborate using GitHub version control.

## Object-Oriented Programming

The project is intended to demonstrate core OOP concepts, including:

- **Classes and objects:** representing the entities used by the application.
- **Encapsulation:** keeping related data and behavior together.
- **Inheritance and polymorphism:** where implemented in the source code.
- **Abstraction:** separating relevant functionality from implementation details.

For specific implementations, consult the C# source files and project report.

## Getting Started

1. Download or clone the repository.
2. Open the folder containing the final C# solution (`.sln`) or project (`.csproj`) in Visual Studio.
3. Restore any required dependencies.
4. Build the solution and resolve any configuration errors.
5. Run the application using the project's configured startup target.

**Requirements:** A compatible .NET SDK or .NET Framework version and a C# development environment. The exact target version should be checked in the project's `.csproj` file.
